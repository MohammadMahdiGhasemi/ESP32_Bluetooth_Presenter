# کنترل پاورپوینت با ESP32 و ریموت مادون‌قرمز

مخصوص ESP32-WROOM-32 معمولی، پاورپوینت نصب‌شده ویندوز و بلوتوث BLE لپ‌تاپ.
USB فقط برای برق، آپلود و تنظیم اولیه است. برنامه واسط ویندوز لازم نیست.
آپلود این برنامه جای برنامه قبلی روی همین برد را می‌گیرد.

## ۱. سیم‌بندی
ابتدا برق برد را قطع کنید. اتصال براساس نوشته پایه‌هاست؛ ترتیب فیزیکی پایه‌ها را حدس نزنید.

| گیرنده IR | ESP32 |
|---|---|
| OUT / S / IN (پایه سیگنال) | GPIO27 |
| GND / منفی | GND |
| VCC / مثبت | 3V3، فقط اگر گیرنده با ۳٫۳ ولت سازگار است |

مدل گیرنده هنوز مشخص نیست. اگر نوشته یا مشخصات آن را نمی‌دانید، قبل از اتصال تغذیه عکس واضح بفرستید. خروجی ۵ ولتی به GPIO ندهید. این پروژه فقط گیرنده IR می‌خواهد؛ LCD و بازر لازم نیست. کابل USB را برای برق وصل کنید.

## ۲. نصب Arduino IDE و کتابخانه‌ها
در Preferences آدرس زیر را به Additional Boards Manager URLs اضافه کنید:
https://espressif.github.io/arduino-esp32/package_esp32_index.json

در Boards Manager بسته «esp32 by Espressif Systems» نسخه **2.0.17** را نصب کنید.
نسخه عمداً ثابت است؛ این پروژه با API کتابخانه BLE قدیمی کار می‌کند و نسخه 3.x را جایگزین نکنید.
در Library Manager کتابخانه **IRremote by Armin Joachimsmeyer نسخه 4.4.1** را نصب کنید.
کتابخانه **ESP32 BLE Keyboard by T-vK نسخه 0.3.2-beta**:
https://github.com/T-vK/ESP32-BLE-Keyboard/releases/tag/0.3.2-beta
ZIP را از مسیر Sketch > Include Library > Add .ZIP Library نصب کنید.
USE_NIMBLE را فعال نکنید؛ کتابخانه BLE دیگری لازم نیست.

## ۳. آپلود
پوشه ZIP پروژه را Extract کنید. فایل ESP32_Presenter/ESP32_Presenter.ino را باز کنید.
Logic.h باید کنار فایل ino بماند.
Board: ESP32 Dev Module؛ Port: پورت برد؛ Upload Speed: 115200.
Partition Scheme: Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS).
اگر حجم برنامه از پارتیشن عبور کرد، Huge APP را انتخاب کنید.
Upload بزنید. اگر روی Connecting ماند، BOOT را تا شروع آپلود نگه دارید و سپس رها کنید.

## ۴. معرفی دکمه‌های ریموت — فقط یک بار
Serial Monitor را روی 115200 تنظیم کنید. حرف انگلیسی L را بفرستید.
طبق پیام‌ها، هر دکمه را کوتاه فشار دهید و رها کنید:
۱. NEXT: بعدی
۲. PREVIOUS: قبلی
۳. PLAY / START: پخش
۴. BACK / EXIT: بازگشت
۵ تا ۱۴. اعداد 0 تا 9 به همین ترتیب

بین فشارها حدود نیم ثانیه فاصله بدهید. استفاده مجدد از یک دکمه پذیرفته نمی‌شود.
پس از پیام SAVED تنظیمات در حافظه باقی می‌ماند، حتی با قطع برق.
هر مرحله ۶۰ ثانیه فرصت دارد. X آموزش را لغو می‌کند؛ L آموزش را از نو شروع می‌کند.
تنظیمات قبلی تا تکمیل موفق آموزش جدید حفظ می‌شود. هنگام آموزش هیچ کلیدی به ویندوز ارسال نمی‌شود.
اگر با فشردن دکمه هیچ خط IR ظاهر نشد، سیم‌بندی، تغذیه، باتری و جهت ریموت را بررسی کنید؛ مدل یا پروتکل ریموت ممکن است پشتیبانی نشود.

## ۵. اتصال بلوتوث
Windows Settings > Bluetooth & devices > Add device > Bluetooth
دستگاه **PPT Remote** را انتخاب کنید. Serial Monitor پیام Bluetooth CONNECTED می‌دهد.
بعد از آموزش، Serial Monitor را ببندید و پنجره پاورپوینت را فعال کنید.
در استفاده بعدی معمولاً اتصال خودکار انجام می‌شود. اگر نشد، دستگاه را از ویندوز Remove کنید و دوباره Pair کنید.

## ۶. استفاده
| دکمه | عملکرد |
|---|---|
| پخش | F5؛ شروع از اسلاید اول |
| بعدی | فلش راست؛ انیمیشن بعدی یا اسلاید بعدی |
| قبلی | فلش چپ؛ حرکت قبلی ارائه |
| بازگشت | Esc؛ پایان نمایش، بدون بستن فایل |
| عدد 5 | بعد از یک ثانیه: 5 و Enter؛ اسلاید ۵ |
| 2 سپس 5 | با فاصله کمتر از یک ثانیه: اسلاید ۲۵ |

رفتن به شماره اسلاید فقط در حالت نمایش ارائه کاربرد دارد. شماره اسلاید باید موجود باشد.
تا چهار رقم پشتیبانی می‌شود؛ صفر تنها ارسال نمی‌شود. بعدی/قبلی/پخش/بازگشت، عدد در حال ورود را لغو می‌کند.
قبل از استفاده زبان کیبورد ویندوز را روی English قرار دهید.
نگه‌داشتن دکمه برای تکرار عمدی اسلاید پشتیبانی نمی‌شود؛ برای هر حرکت، دکمه را رها و دوباره فشار دهید.
فرمان‌های زمان قطع بلوتوث ذخیره یا بعداً بازپخش نمی‌شوند.

## نکته مهم
این دستگاه مثل کیبورد است؛ فرمان‌ها به پنجره فعال می‌روند. ابتدا روی پاورپوینت کلیک کنید.
برای توقف فوری، برق ESP32 را قطع کنید. این پروژه نشانگر لیزری یا حرکت ماوس ندارد.
این نسخه مستقل است؛ برنامه کنترل کارت و LCD قبلی را هم‌زمان اجرا نمی‌کند.
